# 像素农场

一个基于 React + Phaser 制作的 2D 像素农场游戏 Demo。

## 功能

- 农场探索
- 种植
- 浇水
- 作物成长
- 收获
- 商店
- NPC
- 房屋
- 睡觉
- 昼夜系统
- 背包
- 存档
- 游戏帮助
- 游戏画面缩放

## 开发

```
npm install
npm run dev
```

## 构建

```
npm run build
```

## 操作

- `W A S D` / 方向键：移动
- `E`：交互
- `1 ~ 5`：切换快捷栏
- `I`：打开背包
- `T`：结束一天
- `ESC`：关闭当前窗口
- 鼠标滚轮：缩放游戏画面

## 技术栈

- React 18 + TypeScript
- Vite 5
- Phaser 3
- localStorage 存档
